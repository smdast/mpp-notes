# MPP Notes

Windows + Microsoft Edge向けの、日本語の手書き・PDFノートアプリです。GitHub Pagesで動作します。端末内で使う場合はログイン不要で、Google Drive同期を使う場合はGoogle認証を利用します。

## 起動

Node.js 24以上で、このフォルダーを開いて実行してください。

```sh
npm ci
npm run dev
```

表示されたローカルURLをEdgeで開いてください。HTMLファイルの直接起動には対応していません。

```sh
npm test
npm run build
```

ビルド成果物は `dist/` に生成します。PDF用のフォント・CMap・WASMはビルド前に自動コピーし、すべて同じ公開先から配信します。Google Drive未接続時はノートを外部へ送信しません。接続後は、選んだアカウントのアプリ専用領域へノートとフォルダーを自動同期します。

## 使い方

- ペンで描画。指は移動・2本指で拡大縮小。マウスで描くには「ペンのみ描画」を切り替えます。
- P：ペン、H：蛍光ペン、E：線単位の消しゴム、V：移動。
- Ctrl+Z：元に戻す。Ctrl+Shift+Z / Ctrl+Y：やり直し。履歴はページごとに50操作、再読み込みでリセットされます。
- ノート名横の「…」から名前変更・削除。ページ下部の矢印で順序を変更します。
- PDFは100 MB以下・パスワードなしに対応。既存PDFページと追加した通常ページをまとめてPDF出力できます。
- 手書き線は編集可能な点列として保存。PDF出力では最大4倍・長辺8192px（24メガピクセル上限）の透過画像として重ねます。元PDFのページ、回転、CropBoxを保持します。
- ZIPバックアップは形式バージョン1。元PDFと全ノートを含みます。復元時は新しいIDで追加し、既存ノートを置き換えません。圧縮前後の上限は250 MBです。

## 保存について

IndexedDBに自動保存します。元PDFは別ストアに保存し、筆記のたびにPDF本体を書き直しません。書き込みは順番に実行し、トランザクション完了後に「保存済み」を表示します。保存に失敗したら画面上に残る内容をZIPで退避し、容量を確保して「再保存」を押してください。

ブラウザーのデータ削除、プライベートモードの終了、保存領域の消去などでノートが失われる場合があります。定期的にZIPバックアップを取ってください。端末・ブラウザープロファイル・公開URLが変わると別の保存領域になります。ローカルで書いたノートを公開サイトへ移すにはZIPを書き出して復元します。

複数タブの競合はWeb Locksで防止します。Edgeで別の編集タブがある場合は編集を開始しません。手のひらは描画入力に採用しませんが、OSが指として通知する接触は移動操作になる場合があります。実際の筆圧・遅延・ペンボタン・手のひら接触は対応端末で確認してください。

## GitHub Pages

公開リポジトリ `smdast/mpp-notes` の `main` ブランチへ配置し、Settings → Pages → Build and deployment → Sourceを **GitHub Actions** にします。付属のワークフローがテスト、ビルド、公開を実行します。

相対パスでビルドするため、リポジトリ名を変更しても動作します。アプリとソースコードだけが公開され、利用者が保存したノートはリポジトリに含まれません。

## 検証状況

自動テストで座標変換、線との交差判定、Undo/Redo、IndexedDB保存・復元・一括処理のロールバック、ZIP復元・形式検証、混在サイズ・回転PDFを確認しています。

ブラウザーでフォルダー内のノート作成、描画、なげなわ選択・移動・Undo、エリア消去、拡大時の描画面解像度増加を確認済みです。配信サーバー停止後のPWA再起動とノート・フォルダーの復元も確認しています。MPP実機での筆圧・遅延・パームリジェクション・ボタン、指によるスワイプは未確認です。

## 編集と整理（更新版）

- 拡大率・画面密度に応じた高解像度描画と、滑らかな筆圧輪郭を採用しました。表示用サーフェスは長辺8192px・24メガピクセル以内に制限します。
- 消しゴムはストローク単位／エリア消去を切り替え可能。エリア消去は線データを部分分割し、再編集・Undo・PDF出力にも反映します。消しゴムのサイズは画面上の直径です。
- Lでなげなわ選択。囲んだ範囲と交差する線も選択し、選択枠内をドラッグしてまとめて移動します。選択状態は保存・PDF出力しません。
- フォルダーは20階層まで対応。作成、名前変更、ノートの移動に対応。削除時は配下のノートを親フォルダー（最上位なら未分類）へ戻します。空のフォルダーも保存・バックアップに含みます。既存のノートと旧ZIPはそのまま読み込めます。
- 最終ページ下端で1本指をさらに90px以上上へスワイプし、案内が出てから離すとページを追加します。途中のページ、2本指、キャンセル時は追加しません。

## PWA・オフライン

初回のキャッシュ準備完了後は、オフラインでも保存済みのノート、PDF、全描画ツールを使えます。PDF用フォント・CMap・WASM・ワーカーもアプリと一緒にキャッシュします。インストール可能な環境ではサイドバーにボタンが出ます。Edgeのアプリメニューからもインストールできます。

新バージョンは「新しいバージョンに更新」で反映します。保存中・筆記中・保存失敗中は更新による再読み込みを行いません。サービスワーカーはアプリの公開パス内だけで動作し、ノートの内容はキャッシュやネットワークに送信しません。

## ノート管理と連続ページ

起動時は管理専用ページ（`#/library`）を表示します。検索・名前順／更新順の並べ替え・ノートの移動・名前変更・削除に対応します。カードを開くと編集専用ページ（`#/note/ノートID`）になり、ブラウザーの戻る操作も使えます。

フォルダーを選んで「フォルダーを作成」を押すと、その配下に作成します。作成／名前変更欄の「親フォルダー」で作成先や移動先を変更できます。親フォルダーの名前変更・移動は子孫のフォルダーとノートにも反映します。自分の配下への移動や同名への上書きはできません。ZIPは階層と空フォルダーも保持します。

編集ページは用紙の区切りを残して縦に連続します。スクロールで現在ページ表示も切り替わります。ページ一覧を押すと該当ページへジャンプします。画面近くのページだけ描画し、PDFデータは全ページで共有します。線・Undo履歴・用紙設定はページごとに保存します。ページ追加スワイプはノート全体の下端で動作します。

## ペンと図形補正

3本のペンと蛍光ペンに、それぞれ色・太さ・筆圧オン／オフを設定できます。選んだペンと設定はこのブラウザーへ保存し、再起動後も復元します（ノートのZIPとは別の設定です）。筆圧オフは一定幅になります。既存の線は設定変更の影響を受けません。

「図形補正」をオンにすると、書き終わりに直線・円／楕円・長方形（回転を含む）を判定して整えます。通常の筆記を変えにくいよう、開いた曲線や小さな線は補正しません。判定できない形はそのまま残します。補正済みの線も選択・移動・エリア消去・PDF出力・ZIP復元ができます。図形補正はオフにでき、設定を保持します。

ブラウザーで、階層フォルダー作成、連続スクロールと継ぎ目、ページジャンプ、ページ別の描画・履歴、ペン設定の独立と再起動後の保持を確認しました。画面操作から出力したZIPで、2ページ目だけに線が保存され、直線へ補正されていることも確認しています。MPP実機での筆圧の感触と指のスワイプは引き続き未確認です。

## 表示テーマ

管理画面・編集画面のヘッダーで「システム／ライト／ダーク」を選べます。システム設定の変更にも追従し、選択を保存します。用紙はページごとに色を選べ、PDFは元の背景を維持します。新しい暗色用紙には明るい既定ペンを使います。すでに指定した色と筆記済みの旧ページは保持します。既存の設定データにはシステム追従を補います。

## 選択・用紙・スクロールの更新

パンくずの表示は「階層1 > 階層2 > 階層3」に統一しました。フォルダーの内部保存には引き続き `/` を使いますが、UI表示では階層ごとに区切ります。

用紙色は白・クリーム・薄いグレー・暗いグリーン・暗いグレー・カスタム色を選べます。新しい空の用紙はテーマの既定色になり、最初の筆記時にその色を保存します。旧ページに筆記があれば背景の白を保持します。既定ペンは用紙の明暗で選び、利用者が指定した色は変更しません。PDFとZIPにも用紙色を反映します。

なげなわ選択後は四隅のハンドルで拡大縮小、上の丸で回転できます。Shiftを押した拡大縮小は縦横の倍率を揃えます。用紙上の数値指定パネルは表示しません。選択範囲の近くの小型ポップアップでコピー、切り取り、複製、90度回転、削除ができます。操作中はポップアップを隠し、画面内に収まる位置へ配置します。Delete/Backspaceによる削除にも対応し、各操作は1回のUndoで戻せます。

粗いホイール入力を補間し、指・移動ツールでのドラッグ後は慣性で減速します。トラックパッドの細かい入力はブラウザーのスクロールを使います。端末の「視差効果／動きを減らす」が有効な場合は慣性・補間を無効にします。筆記・選択・ページ移動の開始時は進行中の慣性を止めます。

## Google Drive自動同期

標準のOAuthクライアントIDは組み込み済みで、「Googleに接続して同期」から利用できます。利用者にクライアントIDを表示・入力する画面はありません。過去に端末保存された上書き設定は使用せず、アプリの接続設定を使います。権限は `drive.appdata` のみを要求し、アプリ専用の非表示領域を使います。通常のDriveファイルを読み書きする権限は使いません。準備手順は設定画面にもあります。

アプリ使用中に変更後約3秒、および30秒間隔、オンライン復帰・フォーカス復帰時に同期を試みます。筆記中・端末保存中は反映を延期します。アプリを閉じた間の同期は行いません。アクセストークンはメモリーだけで保持し、有効期限後やアプリの再起動後は再接続が必要です。同期の進捗は端末内に保存します。

ノートは変更ごとのZIPと、親の変更IDを持つ履歴を追加して保存します。同時編集は決定的なIDの競合コピーを作成し、削除と編集が重なった場合も編集内容を別コピーへ残します。フォルダーの同時変更は統合して保持します。同期中に端末側が変われば古い受信結果を反映せず、次回に再試行します。履歴は自動削除しないため、利用量に応じてDriveの容量を使います。

同期処理は2端末の変更・削除、同時編集、削除競合、通信中の追加入力、履歴消失、認証切れを模擬して検証しています。実際のGoogleアカウントでの接続確認は、所有者によるCloud設定後に行ってください。


## コピー・貼り付けと画像

選択したストロークはポップアップまたはCtrl+C / Ctrl+Xでコピー・切り取りできます。Ctrl+Vまたは上部の貼り付けボタンで、現在のページの見えている範囲に貼り付けます。別ノート・別ページへの貼り付けに対応し、線の色・筆圧・太さを保持します。クリップボードは版付きテキスト形式で、MPP Notes同士で編集可能なまま受け渡せます。アプリ外へのベクター形式の書き出しは含みません。ブラウザーが読み取りを制限する場合はCtrl+Vを使ってください。

画像もクリップボードから貼り付けられます。20MB・4,000万画素までの読み込める画像を、長辺2048px以下のPNGに変換して端末内に保存します。なげなわで移動・拡大縮小・回転・コピー・削除でき、Undo/Redo、ZIPバックアップ、Drive同期、PDF出力にも保持します。消しゴムは手書き線に作用し、画像の削除には選択ポップアップを使います。画像の追加情報はバックアップ形式1の任意フィールドとして保存し、従来のノートも復元できます。

自動テストではクリップボードの形式検証、独立した複製、画像を含む保存・復元・履歴、および回転・CropBoxを持つPDF上での画像配置を確認しています。


## 描画と表示の調整

図形補正は線の揺れ、四角形の辺のずれ、円・楕円の閉じ方のずれを許容します。水平・垂直から10度以内の直線は用紙の軸に揃えます。それ以外も近くの補正済み直線に対し6度以内なら平行・垂直へ揃えます。図形補正をオフにすると手書きの形を保持します。罫線・方眼は40ページ座標単位（従来26）に広げ、PDF出力にも適用します。取り込んだPDFの背景は元のままです。

表示倍率は25〜800%です。右下から倍率を直接選ぶか、拡大・縮小ボタンやピンチで変更できます。描画キャンバスの解像度には端末のメモリーを守る上限を設けています。

各ペンの「線の種類」で実線／点線を選べます。点線は入力速度によらない間隔の丸い点で描画し、筆圧・色・太さ、コピー、変形、バックアップ、同期、PDF出力に対応します。旧ノートの線は実線のままです。
