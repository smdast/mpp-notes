# MPP Notes

Windows + Microsoft Edge向けの、日本語の手書き・PDFノートアプリです。GitHub Pagesのみで動作し、サーバーやログインは不要です。

## 起動

Node.js 24以上で、このフォルダーを開いて実行してください。

```sh
npm ci
npm run dev
```

表示されたローカルURLをEdgeで開いてください。HTMLファイルの直接起動には対応していません。

```sh
npm test
npm run build
```

ビルド成果物は `dist/` に生成します。PDF用のフォント・CMap・WASMはビルド前に自動コピーし、すべて同じ公開先から配信します。ノートを外部サーバーに送信する処理はありません。

## 使い方

- ペンで描画。指は移動・2本指で拡大縮小。マウスで描くには「ペンのみ描画」を切り替えます。
- P：ペン、H：蛍光ペン、E：線単位の消しゴム、V：移動。
- Ctrl+Z：元に戻す。Ctrl+Shift+Z / Ctrl+Y：やり直し。履歴はページごとに50操作、再読み込みでリセットされます。
- ノート名横の「…」から名前変更・削除。ページ下部の矢印で順序を変更します。
- PDFは100 MB以下・パスワードなしに対応。既存PDFページと追加した通常ページをまとめてPDF出力できます。
- 手書き線は編集可能な点列として保存。PDF出力では最大4倍・長辺8192px（24メガピクセル上限）の透過画像として重ねます。元PDFのページ、回転、CropBoxを保持します。
- ZIPバックアップは形式バージョン1。元PDFと全ノートを含みます。復元時は新しいIDで追加し、既存ノートを置き換えません。圧縮前後の上限は250 MBです。

## 保存について

IndexedDBに自動保存します。元PDFは別ストアに保存し、筆記のたびにPDF本体を書き直しません。書き込みは順番に実行し、トランザクション完了後に「保存済み」を表示します。保存に失敗したら画面上に残る内容をZIPで退避し、容量を確保して「再保存」を押してください。

ブラウザーのデータ削除、プライベートモードの終了、保存領域の消去などでノートが失われる場合があります。定期的にZIPバックアップを取ってください。端末・ブラウザープロファイル・公開URLが変わると別の保存領域になります。ローカルで書いたノートを公開サイトへ移すにはZIPを書き出して復元します。

複数タブの競合はWeb Locksで防止します。Edgeで別の編集タブがある場合は編集を開始しません。手のひらは描画入力に採用しませんが、OSが指として通知する接触は移動操作になる場合があります。実際の筆圧・遅延・ペンボタン・手のひら接触は対応端末で確認してください。

## GitHub Pages

公開リポジトリ `smdast/mpp-notes` の `main` ブランチへ配置し、Settings → Pages → Build and deployment → Sourceを **GitHub Actions** にします。付属のワークフローがテスト、ビルド、公開を実行します。

相対パスでビルドするため、リポジトリ名を変更しても動作します。アプリとソースコードだけが公開され、利用者が保存したノートはリポジトリに含まれません。

## 検証状況

自動テストで座標変換、線との交差判定、Undo/Redo、IndexedDB保存・復元・一括処理のロールバック、ZIP復元・形式検証、混在サイズ・回転PDFを確認しています。

ブラウザーでフォルダー内のノート作成、描画、なげなわ選択・移動・Undo、エリア消去、拡大時の描画面解像度増加を確認済みです。配信サーバー停止後のPWA再起動とノート・フォルダーの復元も確認しています。MPP実機での筆圧・遅延・パームリジェクション・ボタン、指によるスワイプは未確認です。

## 編集と整理（更新版）

- 拡大率・画面密度に応じた高解像度描画と、滑らかな筆圧輪郭を採用しました。表示用サーフェスは長辺8192px・24メガピクセル以内に制限します。
- 消しゴムはストローク単位／エリア消去を切り替え可能。エリア消去は線データを部分分割し、再編集・Undo・PDF出力にも反映します。消しゴムのサイズは画面上の直径です。
- Lでなげなわ選択。囲んだ範囲と交差する線も選択し、選択枠内をドラッグしてまとめて移動します。選択状態は保存・PDF出力しません。
- フォルダーは1階層。作成、名前変更、ノートの移動に対応。削除時は中のノートを未分類へ戻します。空のフォルダーも保存・バックアップに含みます。既存のノートと旧ZIPはそのまま読み込めます。
- 最終ページ下端で1本指をさらに90px以上上へスワイプし、案内が出てから離すとページを追加します。途中のページ、2本指、キャンセル時は追加しません。

## PWA・オフライン

初回のキャッシュ準備完了後は、オフラインでも保存済みのノート、PDF、全描画ツールを使えます。PDF用フォント・CMap・WASM・ワーカーもアプリと一緒にキャッシュします。インストール可能な環境ではサイドバーにボタンが出ます。Edgeのアプリメニューからもインストールできます。

新バージョンは「新しいバージョンに更新」で反映します。保存中・筆記中・保存失敗中は更新による再読み込みを行いません。サービスワーカーはアプリの公開パス内だけで動作し、ノートの内容はキャッシュやネットワークに送信しません。
